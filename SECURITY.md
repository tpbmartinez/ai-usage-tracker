# Security

This is an experimental project. v2.1.2 has known hardening gaps and has not received an independent penetration test. See SECURITY_REVIEW.md. Documentation updates do not fix the runtime code.

Do not post credentials, account exports, private conversations, or live exploit details in public issues. If GitHub's private vulnerability reporting option is available in the Security tab, use it. Otherwise use the contact form at https://timothypaulmartinez.com/ to request a private reporting channel, without sending secrets or exploit details in the initial message. No response-time guarantee is offered.

For an agreed private report, include the version, impact, required attacker access, and minimal reproduction using synthetic data. Avoid testing against live provider systems or other users. No bug bounty is offered.

Security priorities include strict diagnostic allowlisting, message validation and rate limits, safe CSV exports, bounded polling and comprehensive data deletion. No provider-approved status, account-safety guarantee, or absence of vulnerabilities is claimed.
